# homebrew-macup

Homebrew tap for [macup](https://github.com/VitaliiDeveloper/macup): checks, updates and safe cache cleanup for a developer's Mac.

```bash
brew install vitaliideveloper/macup/macup
```

Update with `brew upgrade macup` (`macup update` does it too), remove with `macup uninstall` or `brew uninstall macup`.
